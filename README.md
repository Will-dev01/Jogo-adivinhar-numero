# Jogo de Adivinhação 

Um jogo interativo de adivinhação numérica desenvolvido para treinar a transição de lógica de programação estruturada para manipulação dinâmica do DOM na Web. 

Neste projeto, o jogador precisa descobrir um número aleatório entre 0 e 100. A cada tentativa, o sistema fornece um feedback visual (se o palpite foi alto ou baixo) e constrói um histórico dinâmico na tela. Ao acertar, um modal flutuante é revelado com um prêmio em vídeo!

** Tecnologias Utilizadas **
* **HTML5:** Estruturação semântica, criação de inputs.
* **CSS3:** Estilização, layout flexível (Flexbox).
* **JavaScript (Vanilla):** Lógica matemática, escuta de eventos (Event Listeners), controle de fluxo e manipulação direta do DOM (innerHTML/innerText/classList).

**⚙️ Funcionalidades**
* Geração de número secreto aleatório.
* Validação de dados de entrada.
* Histórico de palpites em tempo real.
* Cálculo estatístico ao final da partida (tentativas totais, erros altos/baixos e média de valores).


**💡 Como rodar o projeto**
Basta fazer o download dos arquivos e dar dois cliques no `index.html` para abrir diretamente no seu navegador de preferência. Nenhuma instalação ou servidor local é necessária.
